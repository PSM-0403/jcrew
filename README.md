# JCREW 농구교실 AI 에이전트 플랫폼

농구학원 운영에 특화된 AI 에이전트 기반 관리 시스템 프로토타입입니다.

---

## 기술 스택

| 구분 | 기술 |
|---|---|
| Frontend | React 19 + Vite |
| AI | 미정 (LLM API 연동 예정) |
| 데이터 | Mock Data (추후 Supabase 연동 예정) |
| 스타일 | Inline CSS |

---

## AI 에이전트 구성

총 6개의 에이전트가 학원 운영 워크플로우에 통합되어 있습니다.

### ① 이탈 위험 감지 에이전트
- **트리거**: 강사 로그인 시 자동 실행
- **동작**: 전체 회원의 출석률·납부 패턴을 스캔해 이탈 위험 회원을 자동 감지
- **결과**: 위험도(높음/보통) 태그 + 관리 방안 제시

### ② 보강 자동 매칭 에이전트
- **트리거**: 회원이 보강 신청 버튼 클릭
- **동작**: 선호 요일·시간대 필터링 후 Claude가 최적 보강 수업 추천
- **결과**: 1~2개 수업 추천 + 추천 이유

### ③ 수업 후 피드백 생성 에이전트
- **트리거**: 출석 체크 완료 후 강사가 실행
- **동작**: 강사 메모 기반으로 출석 회원별 개인 피드백 자동 생성
- **결과**: 회원별 2~3문장 맞춤 피드백

### ④ 학부모/회원 알림 에이전트
- **트리거**: 출석 체크 완료 후 강사가 실행
- **동작**: 출석/결석 현황 기반 문자 초안 자동 생성
- **결과**: 유소년 수업 → 학부모 알림 문자 / 성인 수업 → 회원 본인 알림 문자
- **특이사항**: 수업 카테고리(성인/유소년)에 따라 수신자와 말투 자동 분기

### ⑤ 월간 리포트 자동 생성 에이전트
- **트리거**: 강사가 수동 실행
- **동작**: 전체 회원·수업 데이터 종합 분석
- **결과**: 출석 현황 / 납부 현황 / 수업 운영 현황 / 중점 관리 회원 포함 리포트

### ⑥ 수업 추천 에이전트
- **트리거**: 강사가 신규 회원 정보 입력 후 실행
- **동작**: 카테고리(초등/중등/고등/성인)·선호 요일·시간대 기반 필터링 후 Claude 추천
- **결과**: 적합한 수업 1~2개 + 추천 이유

## 주요 기능

### 강사 측
- 회원 가입 승인/반려
- 수업 개설·수정·삭제 (카테고리·레벨 체계)
- 출석 체크 및 메모
- 회원 현황 (수업 배정, 납부 이력, 강사 메모)
- 갤러리 (수업 사진/영상 관리)
- 공지 작성 및 발송
- AI 에이전트 패널 (전체 에이전트 통합 실행)

### 회원 측
- 수업 신청/취소
- 보강 신청 (AI 자동 매칭)
- 이번 주 수업 일정 확인
- 수강료 납부 (계좌이체/카드)
- AI 챗봇 (수업·출석·납부 관련 질의응답)
- 공지 확인

```bash
npm install

```
