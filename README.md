# 제이크루(J-CREW) 농구교실 관리 시스템

농구교실 운영에 특화된 AI 기반 통합 관리 플랫폼입니다.  
강사/관리자와 회원이 각각의 뷰를 가지며, AI 에이전트·챗봇·실시간 채팅 기능을 포함합니다.

---

## 기술 스택

| 구분 | 기술 |
|---|---|
| Frontend | React 19 + Vite |
| 상태관리 | Zustand |
| 백엔드/DB | Supabase (PostgreSQL + Realtime + Storage) |
| AI | OpenAI GPT-4o-mini |
| 스타일 | Inline CSS |
| 배포 | Vercel |

---

## 환경변수

```
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
VITE_OPENAI_API_KEY=your_openai_api_key
```

---

## 실행 방법

```bash
npm install
npm run dev
```

## 주요 기능

### 강사/관리자

| 기능 | 설명 |
|---|---|
| 대시보드 | 가입 신청 승인/반려, 이탈 위험 회원 현황, 보강 신청 배정, 계좌이체 확인, 월간 리포트 |
| 출석 체크 | 월별 캘린더, 날짜별 출석 입력, 휴강 처리, 수업 내용·피드백 저장 |
| 학부모 알림 | 수업 내용·피드백 기반 AI 메시지 자동 생성 → 강사 검토 후 채팅으로 전송 |
| 수업 관리 | 수업 개설·수정·삭제 (요일·시간·정원·레벨 설정) |
| 회원 현황 | 검색·필터링, 수업 배정, 출결 이력, 납부 이력, 정보 수정, 강사 메모, 회원 삭제 |
| 갤러리 | 수업별 사진·영상 업로드·관리 |
| 채팅 | 회원별 1:1 채팅 (카카오톡 스타일), 메시지 삭제, 채팅방 나가기 |
| AI 에이전트 | 이탈 위험 회원 분석, 월간 리포트 자동 생성 |
| 공지 | 공지사항 작성·관리 |

### 회원

| 기능 | 설명 |
|---|---|
| 홈 | 납부 현황, 다음 수업 일정, 휴강 안내, 수강료 납부(계좌이체/카드) |
| 내 수업 | 수업 취소, 보강 신청, 잔여 보강 횟수, 출결 이력, 배정된 보강 확인 |
| 갤러리 | 본인 수강 수업의 사진·영상 확인 |
| 채팅 | 강사와 1:1 실시간 채팅, 미읽음 뱃지 실시간 업데이트 |
| AI 챗봇 | 수업 일정·출결·납부·보강·수업내용·피드백 등 전반적인 질의응답 |
| 공지 | 공지사항 확인 |
| 내 정보 | 연락처·성별·학년·학교·셔틀 등 개인정보 수정, 비밀번호 변경 |

## AI 에이전트 구성

### ① 이탈 위험 회원 분석
- 규칙 기반 위험도 산정 (연속결석 횟수, 출석률, 납부 여부)
- 위험 회원에 한해 GPT-4o-mini가 한 줄 조치 코멘트 생성
- 결과 DB 저장 → 대시보드 상시 표시

### ② 월간 리포트 자동 생성
- 실제 출석 데이터 기반 평균 출석률 계산
- 납부 현황, 수업 현황, 위험 회원 현황 종합
- GPT-4o-mini가 4개 항목 리포트 작성

### ③ 학부모/회원 알림 메시지 생성
- 출석 체크 후 수업 내용·피드백·출결 현황 기반으로 회원별 메시지 초안 생성
- 강사가 각 메시지 수정 후 채팅으로 개별 전송

---

## 로그인 방식

- **강사**: 별도 코드 입력
- **회원**: 이름 + 부모님(본인) 연락처 뒷 4자리 + 비밀번호

---

## 데이터베이스 테이블

| 테이블 | 용도 |
|---|---|
| members | 회원 정보 (상태: pending/active/deleted) |
| classes | 수업 정보 |
| enrollments | 수업-회원 매핑 |
| attendance | 출결 기록 |
| payments | 납부 이력 |
| pending_payments | 계좌이체 대기 |
| class_notes | 수업 내용 |
| class_feedback | 회원별 피드백 |
| makeup_requests | 보강 신청 |
| messages | 강사-회원 채팅 (hidden_by_coach 컬럼으로 비대칭 삭제) |
| notices | 공지사항 |
| gallery | 갤러리 사진·영상 |
| agent_results | AI 에이전트 실행 결과 저장 |
