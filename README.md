# 제이크루(J-CREW) 농구교실 관리 시스템

> 유소년 농구교실에서 3년간 코치로 일하면서 회원 관리, 출석 체크, 학부모 소통 등 반복적인 행정 업무에 많은 시간을 쏟았습니다.  
> 이 경험을 바탕으로 현장에서 실제로 불편했던 점들을 직접 해결하고자 기획·개발한 농구교실 전용 AI 통합 관리 플랫폼입니다.

**배포 주소**: [jcrewbasketball.vercel.app](https://jcrewbasketball.vercel.app)

---

## 담당 역할

**기획 · 개발 · 배포 1인 풀스택**

## 쌓이는 데이터로 알 수 있는 것

- **출결 + 결석 사유**: 연락 없이 빠지는 아이를 미리 알아챌 수 있음 (연속 무단 결석, 최근 무단 결석 횟수)
- **보강 기록**: 결석한 수업을 보강으로 채웠는지 반영한 실제 출석률
- **납부 + 출결**: 미납과 출석 저하가 겹치는 회원
- **월별 집계**: 출석률과 무단 결석 비율이 달마다 어떻게 변하는지

## 상세 기능

### 강사/관리자 화면

**대시보드**
- 신규 가입 신청 승인/반려
- 운영 지표 카드: 이탈 위험 단계별 회원 수, 월별 출석률, 월별 무단 결석 비율
- 이탈 위험 회원 현황 (AI 에이전트 실행 결과 상시 표시)
- 보강 신청 목록 확인 및 회원이 고른 수업·날짜로 승인 (수업을 고르지 않은 신청은 수업·날짜·메모 입력 후 배정)
- 계좌이체 완료 신청 확인 및 납부 처리
- 월간 운영 리포트 표시

**출석 체크**
- 월별 캘린더 + 날짜 선택으로 출석/결석 입력, 결석이면 사전 연락/무단 선택
- 승인된 보강 회원은 해당 날짜·수업 목록에 "보강" 표시와 함께 나타나 같은 방식으로 출결 체크
- 날짜별 휴강 처리
- 수업 내용(class_notes) 저장 — 날짜·수업별 누적
- 회원별 피드백(class_feedback) 저장
- 학부모/회원 알림 메시지 AI 자동 생성 → 강사 검토·수정 후 개별 전송

**회원 현황**
- 이름 검색, 요일·수업별 필터링
- 수업 배정/해제
- 출결 이력, 납부 이력 조회
- 회원 정보 수정 (이름·연락처·학년·학교·성별·셔틀 등)
- 강사 메모 작성
- 전화번호 탭 → 확인창 → 바로 전화 연결 (모바일)

**채팅**
- 카카오톡 스타일 채팅방 목록 + 대화창
- 메시지 개별 삭제, 채팅방 나가기 (회원 메시지는 유지, 강사만 숨김)

**AI 에이전트**
- 이탈 위험 회원 분석: 규칙 기반 위험도(매우높음/높음/보통)와 걸린 규칙(사유) + AI 한 줄 조치 코멘트
- 월간 리포트 자동 생성: 출석·납부·수업·위험 회원 현황 종합 리포트

### 회원 화면

**홈**
- 납부 현황 (미납 시 배너 알림)
- 다음 수업 날짜 (휴강 반영)
- 휴강 안내 배너
- 수강료 납부 (계좌이체 신청 / 카드 결제)

**내 수업**
- 등록 수업 확인 및 취소
- 보강 신청 (시간대별 수업 목록에서 수업 선택 → 이번 달 남은 날짜 선택, 신청 시 강사에게 채팅 알림)
- 잔여 보강 횟수 표시
- 출결 이력 월별 조회
- 배정된 보강 확인

**채팅**
- 강사와 실시간 1:1 채팅
- 미읽음 메시지 수 뱃지 실시간 업데이트

**AI 챗봇**
- 수업 일정, 출결 현황, 납부 이력, 보강 신청 현황
- 최근 수업 내용 및 강사 피드백 이력
- 다음 수업 날짜 (휴강 자동 반영)
- 학원 정보, 연락처, SNS 안내

**내 정보**
- 연락처, 성별, 학년, 학교, 셔틀, 주소 수정
- 비밀번호 변경 (확인 입력 후 저장)

## AI 에이전트 구조

```
① 이탈 위험 회원 분석
   출결 데이터 수집 → 규칙 기반 위험도·사유 산정 → AI 한 줄 코멘트 생성 → DB 저장 → 대시보드 반영
   규칙 (src/analytics/attendanceMetrics.js)
   - 연속 무단 결석 3회 → 높음 (미납이면 매우높음)
   - 최근 5회 중 무단 결석 3회 → 보통
   - 미납 + 출석률 60% 미만 → 높음 / 출석률 50% 미만, 미납 + 출석률 70% 미만 → 보통

② 월간 리포트 자동 생성
   실제 출석/납부/수업 데이터 수집 → GPT-4o-mini 리포트 작성 → DB 저장

③ 학부모/회원 알림 메시지 생성
   수업 내용 + 피드백 + 출결 현황 → AI 회원별 메시지 초안 생성 → 강사 검토·수정 → 채팅 전송
```

## 기술적 의사결정

| 결정 | 이유 |
|---|---|
| Supabase Realtime 채택 | 별도 서버 없이 WebSocket 기반 실시간 채팅 구현 |
| Zustand 상태관리 | 탭 전환 시 에이전트 실행 상태·채팅 메시지 유지 필요 |
| GPT-4o-mini 선택 | 응답 속도와 비용의 균형, 한국어 품질 적합 |
| 규칙 기반 + AI 혼합 | 이탈 위험 감지는 규칙 기반으로 정확도 확보, AI는 코멘트 생성에만 활용해 비용 절감 |
| 이탈 신호를 "무단 결석"으로 정의 | 코치로 일하며 보니 말없이 3번 이상 빠진 아이는 대부분 그만둬서, 결석에 사전 연락/무단을 기록하고 연속 무단 결석을 위험 신호로 사용 |
| 출석률과 이탈 신호 분리 | 출석률은 보강 출석까지 포함하고, 이탈 신호는 무단 결석만 셈. 지표 정의는 `src/analytics/attendanceMetrics.js`에서 관리 |
| hidden_by_coach 컬럼 | 강사가 채팅방을 나가도 회원 메시지 이력은 유지 (비대칭 삭제) |
| Vercel Serverless Function 프록시 | OpenAI API 키를 서버사이드에서만 사용, 브라우저 번들 노출 차단 |
| 로그인 서버사이드 처리 | 회원 비밀번호를 클라이언트에 노출하지 않도록 인증 로직을 Vercel Serverless Function으로 이동 |
| Supabase RLS 활성화 | 전체 테이블 Row-Level Security 적용으로 비인가 접근 차단 |
| PWA 적용 | 홈 화면 설치·전체화면 실행으로 네이티브 앱에 가까운 UX 제공 |

## 실행 방법

```bash
npm install
npm run dev
```

로그인·AI 챗봇(`/api/*`)은 Vercel 서버 함수라 `vite` 개발 서버에는 없어서, 개발 중에는 배포된 사이트의 서버 함수로 프록시합니다 (`vite.config.js`).

> 현재 DB의 회원·출결 데이터는 모두 더미입니다. 실제 회원 데이터는 개인정보 보호를 위해 보관하지 않습니다.

### 환경변수 설정

**.env (클라이언트)**
```
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

**Vercel 환경변수 (서버사이드 전용)**
```
OPENAI_API_KEY=your_openai_api_key
```
